# note 論文リライター

note の記事を、Microsoft Edge に組み込まれた LLM（Phi-4-mini、Prompt API）で、論文のように読みやすい構成に書き換える拡張機能です。書き換えは端末の中だけで行われ、記事の本文が外部に送られることはありません。

書き換えたあとの構成:

1. タイトル（内容に合わせて付け直したもの）
2. 要約
3. 目次（節へのリンク）
4. 本文（各段落の最初の文がその段落の要点になる書き方。最初の文だけを拾い読みしても内容がわかる）

## 必要なもの

- Microsoft Edge 138 以降の Canary または Dev チャネル
- `edge://flags` で「Prompt API for Phi mini」を Enabled にして、Edge を再起動
- 内蔵モデルの条件を満たす端末（GPU のメモリやディスクの空き。モデルは最初に使ったときに数 GB ダウンロードされる）

## 入れ方

1. `edge://extensions` を開く
2. 左下の「開発者モード」をオンにする
3. 「展開して読み込み」で、このフォルダを選ぶ

## 使い方

note の記事（`https://note.com/<ユーザー>/n/<記事 ID>`）を開くと、右下に「論文風に書き換える」ボタンが出ます。押すと本文が書き換わり、もう一度押すと元の記事と切り替わります。

## 仕組み

- 本文（`#note-body`）を段落ごとに取り出し、モデルの文脈に収まる大きさに分けます。
- 分けた部分ごとに、見出しと段落を持つ 1 つの節として書き換えます。
- 各節の見出しと各段落の最初の文から、タイトルと要約を作ります。

## 制限

- 有料記事は、見えている部分だけが対象です。
- 画像、埋め込み、表は書き換えたあとには残りません。
- 小さいモデルなので、長い記事は時間がかかり、言い回しが不自然になることがあります。
- 独自ドメインの note（note pro）には対応していません。
